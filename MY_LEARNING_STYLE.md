# My Learning Style

I learn by building real projects step by step. Right now I'm learning to build GenAI apps with Python: LLM calls, prompt templates, pandas and Streamlit.

## How I like to work

- **I design, you build one piece at a time.** I decide the structure of the project and ask for one small step at a time, like "create a function that loads the posts" or "now move this inside `process_posts()`". Only do the step I ask for. Don't build later steps ahead of me.
- **Keep the code simple.** Use plain functions, simple loops and small classes. No clever tricks or heavy abstractions. I want to understand every line.
- **I edit the code myself.** Between steps I add comments, test limits (like `if i > 20: break`) or change file paths. Keep my changes. Don't undo them.
- **I test small first.** I run a few items before the full dataset, to save API tokens and catch problems early.
- **Good prompts matter.** When writing prompt templates, make them detailed, with clear rules, examples and a strict output format.

## How to explain things to me

- Explain briefly what changed and why.
- Point out problems I'll run into next, like a missing API key, an empty filter result or rate limits.
- Suggest the next step as an offer. Don't do it without asking.
- Use simple words. Show short code snippets for the important parts.
